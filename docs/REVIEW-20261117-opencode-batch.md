| S00284 | line x1（触点斜线上端） | 18.75 | 18.5 | 1/4 格；须与 S00286 保持镜像对称 |
| S00286 | line x1（触点斜线上端） | 41.25 | 41.5 | 1/4 格；须与 S00284 保持镜像对称 |

原因归纳：这三处的端点不是几何求交得到的，而是取值时用了 1/4 格步长（.75 / .25）。同批其余 5 件没有这个问题，所以不是画法不一致，是这三个数值的取整步长错了。

修正后须：重渲染 200dpi 与标准原图并排比对，更新各自 README 的 `.elmt` SHA256，`python3 tools/check_release.py` 输出 exit 0。
