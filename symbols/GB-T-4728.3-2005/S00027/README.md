## 原页图形与QET适配

原文图形无端口标记、无引线；QET 适配在顶线两端各设一端口（端口 1 朝西、2 朝东），在中性点托架底设一端口（端口 3 朝南）。圆内 GS/III 为发电机标识，不设端口。点阵背景为参考栅格，未绘入元件。
