### 与标准印刷图的比对

- 内圆/外圆直径比：标准印刷图实测约 54:113（1:2.09），本件取 68:136（1:2.00）。为保持"直径全为整格偶数倍"的取整体系，外圆未按 2.09 放大到 142。
- 屏蔽圆虚线：标准印刷图为**约 8 段均匀虚线**（每段约 35°，间隙约 10°）。本件用 QET 原生 `line-style:dashed`，虚线节距由 QET 依线宽自动生成，段数（导出后约 14 段）与印刷图不逐一对应。如需严格等段，需改用逐段折线弧，本件未采用。
