## 原页图形与QET适配

独立查看原页，确认图形为五条平行横线，上方一个竖直胶囊（标准称椭圆，实印为圆角长圆），胶囊底部引出竖直直线，该直线带两处箭头尖：上尖指向第1条横线、下尖指向第4条横线，两个箭头之间的线段穿过第1–3条横线。这与备注"箭头所指的两根在同一电缆内"一致——被箭头尖点到的第1根与第4根同属该电缆。

按 300dpi 渲染后 3 倍放大裁图实测（mm）：线长 20.97；线间距自上而下 1.92 / 1.61 / 3.36 / 1.78（第3–第4条间距明显加大）；胶囊 3.78 宽 × 7.28 高；胶囊底距第1条线 5.21；箭头翼宽 1.13、翼高 0.85；线宽 0.23。

本件以"线长取 8 格 = 272 单位"为主尺度，按上述实测比例等比换算（缩放系数约 3.29）：五线 y=163 / 188 / 209 / 252.5 / 275，胶囊 49 宽 × 94.5 高、中心 x=136、顶端 y=0.5，箭头尖 y=163 与 252.5。定义外框 272×276，hotspot=(136,138)。所有坐标取整数或半格。

注：同页 S00009 把三线间距取整为 1 格（34 单位）；本件保留原图实测间距比（约 0.74 / 0.62 / 1.28 / 0.68 格），未强行对齐 1 格，以免改动第3–第4条的加大间距这一图形特征。两件并排时密度略有差别，是有意取舍。

标准未给定绝对 mm，本文件不把印刷或导出缩放换算为标准尺寸。

端口 10 个：左端 (0,163)、(0,188)、(0,209)、(0,252.5)、(0,275) 朝西；右端 (272,同 y) 朝东。这些连接点是 QET 适配，不是额外的标准图形。

## 关于胶囊实现（实测结论）

QET 0.100.1-dev 不接受 `<ellipse>` 元素写法（同 S00009 的结论）：结构检查照样报 OK，`--export-pdf` 后该图元消失。本件胶囊改用 26 段折线近似（两段直边 + 两个各 12 段的半圆），逐段由 `line` 图元绘制，端点取半格取整。

首版曾因半圆参数化写错（顶半圆用了 `cx - r·cosθ`）导致顶部出现一条横跨斜线、胶囊不闭合；改为 `cx + r·cosθ` 后闭合。记录在此，供后续同类件复用时避坑。
