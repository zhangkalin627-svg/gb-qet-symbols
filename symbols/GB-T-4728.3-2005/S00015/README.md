## 图形实测尺寸

尺寸单位为 QET 画布单位。

- 外框：408 × 136
- hotspot：`(204, 68)`
- 导线（主水平线）：y=68，x 从 0 到 374
- 终端弧（导体一半）：右凸半圆，半径 34，包围盒 `(340, 0, 68, 68)`，圆心 `(374, 34)`；弧底端点 `(374, 68)` 与水平线右端相接，弧最右点落在 x=408
- 绝缘层弧：一段椭圆弧，包围盒 `(292, 0, 164, 98)`，从半圆顶点 `(374, 0)` 向左下延伸至 `(292, 49)`；与半圆在顶点相切（切线水平），无折角
- 绝缘层短横线：y=49（主水平线上方 19），x 从 227 到 292，接绝缘层弧的末端

> 标准只给图形构成规则，未给定毫米尺寸；上述数值是本件的建模取整，**不是标准规定值**。

### 与标准印刷图的比对

- 比例：标准印刷图实测主水平线长约 300 px、半圆半径约 36 px，半径/线长 = 0.120；本件 34/374 = 0.091。两者不完全一致——本件的半圆半径与线长直接沿用同页 S00014（03-01-14）的取值，以保证同族符号在同一画布尺度下外观统一；按标准图单独折算应取约 45 单位半径。
- 绝缘层短横线：标准图实测长约 52 px（约 65 单位），距主水平线约 15 px（约 19 单位）；本件取 65 长、19 高，比例与标准图一致。
- 弧的形态：标准印刷图的导体弧与绝缘层弧**是同一条连续曲线**（一条约 250° 的平滑勾勒，没有接缝）。本件用 QET 的两段几何（180° 半圆 + 椭圆弧）拼接；因接点处两段切线都水平，视觉上无折角，但曲率在中段与印刷图有差异。本件未做逐点拟合。
- 导体弧跨度：同 S00014，标准印刷图的弧顶略偏向圆心右侧（约 160° 弧），本件画标准 180° 半圆。
