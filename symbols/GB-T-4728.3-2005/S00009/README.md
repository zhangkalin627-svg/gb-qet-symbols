## 关于椭圆实现（实测结论）

QET 0.100.1-dev 不接受本件最初试用的 `<ellipse x y rx ry>` 元素写法：`--check-elements` 仍报 `OK (6 terminals)`，但 `--export-pdf` 渲染后椭圆完全消失，只剩三条横线。即结构检查通过不等于图元被渲染。

因此本件改用 48 段折线近似椭圆，逐段由 `line` 图元绘制。48 段在整数坐标取整后，上下极点可能出现 1 个画布单位的微小不平顺（约 1/34 格），在实际图纸尺寸下不可见，但不属于严格解析椭圆。
