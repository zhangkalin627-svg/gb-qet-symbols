## 图形实测尺寸

尺寸单位为 QET 画布单位。

- 外框：408 × 136
- hotspot：`(204, 68)`
- 导线（水平线）：y=68，x 从 0 到 374
- 终端弧：右凸窄半椭圆，高 70、外凸约 17，包围盒 `(357, 33, 34, 70)`；弧端点 `(374, 33)` 与 `(374, 103)`，钩居中于横线 y=68，线端 (374,68) 落在钩直径中点；弧最右点 x=391

> 标准只给图形构成规则，未给定毫米尺寸；上述数值是本件的建模取整，**不是标准规定值**。

### 与标准印刷图的比对

- 比例：标准印刷图实测水平线长约 311 px、半圆半径约 28 px，半径/线长 = 0.0900；本件 34/374 = 0.0909，偏差约 1%。
- 线长取整：311 px ≈ 392 单位；为与同页 S00013 共用 408 外框宽度（408 − 34 = 374），本件取 374，弧最右点正好落在外框右沿。
- 弧的跨度：标准印刷图的弧顶略偏向圆心右侧（约 160° 弧），本件用 QET `<arc>` 画标准 180° 半圆，弧顶在圆心正上方。这是本件与印刷图的已知差异，未做逐点拟合。
