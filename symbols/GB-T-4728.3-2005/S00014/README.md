## 图形实测尺寸

以 QET 画布单位计，1 格 = 34 单位，坐标为整数。

- 外框：408 × 136
- hotspot：`(204, 68)`
- 导线（水平线）：y=68，x 从 0 到 374
- 终端弧：右凸半圆，半径 34，包围盒 `(340, 0, 68, 68)`，圆心 `(374, 34)`；弧底端点 `(374, 68)` 与水平线右端相接，弧最右点落在 x=408（外框右沿）

> 标准只给图形构成规则，未给定毫米尺寸；上述数值是本件的建模取整，**不是标准规定值**。

### 与标准印刷图的比对

- 比例：标准印刷图实测水平线长约 311 px、半圆半径约 28 px，半径/线长 = 0.0900；本件 34/374 = 0.0909，偏差约 1%。
- 线长取整：按 1 格 = 34 单位折算，311 px ≈ 392 单位；为与同页 S00013 共用 408 外框宽度（408 − 34 = 374），本件取 374，弧最右点正好落在外框右沿。
- 弧的跨度：标准印刷图的弧顶略偏向圆心右侧（约 160° 弧），本件用 QET `<arc>` 画标准 180° 半圆，弧顶在圆心正上方。这是本件与印刷图的已知差异，未做逐点拟合。
