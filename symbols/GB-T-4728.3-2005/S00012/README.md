## 图形实测尺寸

以 QET 画布单位计，1 格 = 34 单位，坐标为整数。

- 外框：272 × 136
- hotspots：`(136, 34)`
- 大空心圆：直径 68，圆心 `(136, 34)`，即圆顶 y=0、圆底 y=68
- 内导体横线：y=34，x 从 0 到 252，正好穿过圆心
- 圆底短横线：y=68，x 从 98 到 174（宽 76，略宽于圆径 68），紧贴圆底
- 竖直引线：x=136（短横线中点），从 y=68 向下至 y=102
- 外导体横线：y=102，x 从 136 到 252
- 右端端子圆：直径 20，圆心 `(262, 34)` 与 `(262, 102)`

> 标准只给图形构成规则，未给定毫米尺寸；上述数值是本件的建模取整，**不是标准规定值**。

## 端口（端子）

3 个端子，QET 方向按位掩码记录：

- `(0, 34)` 朝西 — 内导体左端自由端
- `(272, 34)` 朝东 — 内导体右端子
- `(272, 102)` 朝东 — 外导体右端子

## 测试范围

- QET 0.100 `--check-elements`：3 terminals，0 warning，0 failure
- 内嵌工程 `--export-pdf` 导出 A3 后 `pdftoppm -r 200` 出图，逐项核对：横线穿圆心、圆底短横线对称且贴底、竖线落在短横线中点、右端两小圆分别接两条横线末端并上下对齐
- 与已发布 S00011（同页同族）同图对照画法一致
- **未做**：QET 编辑器内手工拖放与连线测试；带实际线束的工程验证

## 说明

导出 PDF 时 QET 0.100 会给未连接端子画红/蓝短标记。经官方符号 `20103000_and.elmt` 同模板复现确认，属软件导出行为，不是本件缺陷。

## 安装

把 `S00012.elmt` 放进 QET 用户符号目录（`~/.local/share/qelectrotech/elements/` 或对应平台的用户目录）下的任意分类子目录，重启 QET 后可在元素面板找到。也可作为 `embed://gb_4728/2005/part03/gb4728_3_2005_S00012.elmt` 内嵌进 `.qet` 工程。
