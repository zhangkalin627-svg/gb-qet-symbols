## 图形实测尺寸

尺寸单位为 QET 画布单位。

- 外框：408 × 136
- hotspots：`(204, 34)`
- 大空心圆：直径 68，圆心 `(189, 34)`，即圆顶 y=0、圆底 y=68
- 内导体横线：y=34，x 从 0 到 387，正好穿过圆心
- 圆底短横线：y=68，x 从 155 到 223（宽 68），紧贴圆底
- 竖直引线：x=189（短横线中点），从 y=68 向下至 y=102
- 外导体横线：y=102，x 从 189 到 386
- 右端端子圆：直径 20，圆心 `(397, 34)` 与 `(396, 102)`

## 端口（端子）

2 个端子，QET 方向按位掩码记录：

- `(408, 34)` 朝东 — 内导体右端子
- `(408, 102)` 朝东 — 外导体右端子

左端为自由端，不设端子。

## 安装

把 `S00012.elmt` 放进 QET 用户符号目录（`~/.local/share/qelectrotech/elements/` 或对应平台的用户目录）下的任意分类子目录，重启 QET 后可在元素面板找到。也可作为 `embed://gb_4728/2005/part03/gb4728_3_2005_S00012.elmt` 内嵌进 `.qet` 工程。
