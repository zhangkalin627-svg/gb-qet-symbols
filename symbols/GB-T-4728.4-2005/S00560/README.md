## 原页图形与 QET 适配

- 几何比例（实测，300 dpi 渲染）：点阵间距约 28 px；矩形外框 px x 45..124、y 73..98（宽 79 px、高 25 px），中心 (84.5,85.5)；仅左引线 y≈86，左端 x≈31；上方滑动触点：竖线 x≈82 自 y≈31 下至箭头，箭头顶边 y≈54、x 74..90，箭头尖约 (82,76)，顶水平线 y≈31 自 x≈82 至 x≈137；右侧断开位置黑块 px x 131..143、y 75..98。QET：矩形 (-14,-4.5) 宽 28、高 9；左引线 (-19,0)-(-14,0)；竖线 (-1,-19.5)-(-1,-11)；顶水平线 (-1,-19.5)-(19,-19.5)；箭头多边形 (-4,-11)、(2,-11)、(-1,-3.5)；黑块四边形 (16.5,-4)、(21,-4)、(21,4.5)、(16.5,4.5)。
