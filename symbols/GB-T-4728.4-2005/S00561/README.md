## 原页图形与 QET 适配

- 几何比例（实测，300 dpi 渲染）：点阵间距约 28 px；矩形外框 px x 44..125、y 76..100（宽 81 px、高 24 px），中心 (84.5,88)；引线 y≈87，左端 x≈29、右端 x≈139；上方滑动触点：竖线 x≈85 自 y≈29 下至箭头，箭头顶边 y≈55、x 81..88，箭头尖约 (85,77)，顶水平线 y≈29 自 x≈85 至 x≈141。QET：矩形 (-14.5,-4.5) 宽 29、高 9；引线 (-20,0)-(-14.5,0)、(14.5,0)-(20,0)；竖线 (0,-21)-(0,-12)；顶水平线 (0,-21)-(20.5,-21)；箭头多边形 (-1.5,-12)、(1,-12)、(0,-4)。
- 端口适配：原文图形为矩形加两端引线，上方一根竖线带向下箭头触及矩形顶边、顶端向右折水平线；QET 适配设三端口：1=左引线外端 (-20,0) w、2=右引线外端 (20,0) e、3=顶水平线右端 (20.5,-21) e。
