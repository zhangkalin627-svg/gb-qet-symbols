- 几何比例（实测，300 dpi 渲染）：点阵间距约 29.6 px；左引线 px x=32、y 33..91；横杠 y=91、x 32..67；斜臂 (54,79)-(91,150)，与横杠交于 (61,91)；斜臂顶端短横 (49,81)-(60,76)，与斜臂近垂直、交于斜臂顶端 (54,79)；下引线 x=91、y 150..208；右引线 x=91、y 31..92。QET：左引线 (10,10)-(10,30)；横杠 (10,30)-(22,30)；斜臂 (17.5,26)-(30,50)，与横杠交于 (20,30)；短横 (16,26.5)-(19.5,25)；下引线 (30,50)-(30,69.5)；右引线 (30,10)-(30,30)。
