# S00236 — 吸合时的过渡动合触点

- 来源：GB/T 4728.7-2022（IEC 60617 database），2022 版现行版；PDF 第 13 页 / 印刷第 7 页；出版标准序号 GB/T 4728.7 07-03-01；S 号 S00236；IEC 发布 2001-07-01；状态：标准
- 名称：吸合时的过渡动合触点 / Passing make contact when actuated
- 关键词：触点，开关；功能类别：K 处理信号或信息；应用：电路图，接线图，功能图，概略图
- 备注：当动作器件被吸合时，此触点短时闭合
- 形状类别：直线

## 原页图形与 QET 适配
