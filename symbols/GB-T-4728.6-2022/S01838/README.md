## 原页图形与 QET 适配

- 原页：点阵间距约 29.5 px；三主竖线 x=20、60、100，各分四段 (10–20、70–80、90–100、150–160)；每列上下各 5 个右凸半圆（真半圆，Ø10，弦 x=列线，y 20–70 与 100–150，凸至列线+5）；双横线 y=80 与 y=90，均 (20,80)-(100,80) 与 (20,90)-(100,90)；移相箭头（S01846 形式）：对角线 (10,140)-(120,100)，箭杆 (120,100)-(120,113)，三角 (118,113)-(123,113)-(120,119)。量取：弧在 y=22/28/32 行的 x 位置与“弦在列线、凸至列线+5”一致；双横线、竖线分段、箭头均与原图一致。
- QET：原文图形为三列绕组、双横线与移相箭头，无端口标记；QET 适配在三竖线两端各设一端口（端口 1 朝北、2 朝南、3 朝北、4 朝南、5 朝北、6 朝南）。点阵背景为参考栅格，未绘入元件。
