# GB-QET Symbols

AI协助制作的QElectroTech电气符号候选集合，分批记录来源、文件SHA256、独立核对结果及QET版本。

## 范围

首批依据GB/T 4728.3-2005（导体和连接件）制作。后续依据哪一部分、哪一年版，以各批清单为准。不同年份不可互称等同。

本仓库不提供标准原文、标准页截图、公司图纸、万鼎材料或内部设备设计资料。第三方QET原有集合不混作我方重画件；如发布QET衍生件，将单独标记来源和许可。

## 发布状态

当前为仓库说明骨架，尚无符号批次发布。候选不等于已核对，不等于可生产使用；本仓库不作标准认证或安全结论。

每批在独立核对返回并完成发布检查后入库，记录：

- 文件路径、SHA256及来源标准号/年份/符号号；
- 原文图形与QET端口/引线适配的区别；
- 独立核对状态和仍未核对项；
- QET实测版本与打开、旋转、接线、保存重开的实际观察；
- 批次日期和变更记录。

## 使用边界

使用者须按目标QET版本和工程用途自行复核。不得把局部图形核对扩大为全库标准符合、工程验收或实机安全保证。
